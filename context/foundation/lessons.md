## Never list changed files in commit messages

- **Context**: Commit messages created during implementation and other project workflows.
- **Problem**: Listing changed file paths adds clutter and obscures the change's intent.
- **Rule**: Never list changed files in commit messages. Keep the message focused on the change and its intent.
- **Applies to**: all
